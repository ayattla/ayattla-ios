# آيات تتلى | AYAT TUTLA — تطبيق iPhone وiPad

تطبيق أصلي بـ SwiftUI لكل أدوات موقع ayattla.com، مجاني، ويعمل دون إنترنت.

- `HANDOFF.md` — أين وصل المشروع وما التالي.
- `docs/` — التدقيق، المعمارية، عقد الواجهات، المحتوى والتراخيص.
- `design/` — لوحات التصميم.
- `app/` — مشروع Xcode (XcodeGen) والحزم.
- `tools/` — بناء حزمة المحتوى والبيانات الذهبية والفحوص.
- `.github/workflows/ci.yml` — بناء واختبار تلقائي على macOS.
