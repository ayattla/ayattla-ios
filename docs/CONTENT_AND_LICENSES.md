# CONTENT_AND_LICENSES — مصادر المحتوى وحقوق استخدامها في التطبيق

الحالة: **يحتاج تحققا قبل التضمين** = لا يُشحن داخل التطبيق قبل إذن مكتوب أو رخصة واضحة.

## قرارات معلقة على المالك

1. مراسلة Quran Foundation لطلب إذن تخزين التوقيتات في التطبيق.
2. مراسلة EveryAyah وhisnmuslim.com بخصوص التنزيل دون إنترنت.
3. اعتماد خط المصحف (Amiri Quran الحالي أو KFGQPC الرسمي).
4. اختيار الترجمات التي تُضمَّن في v1 بعد فحص رخصها.
